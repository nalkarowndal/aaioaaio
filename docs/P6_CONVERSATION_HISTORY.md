# P6 — 대화 기록 영속화·검색·복원

## 기반 및 배치

- 기반: P5 브랜치 `feature/p5-unified-chat-composer`. P5가 `main`에 병합되기 전까지 P6는 **P5를 베이스로 하는 스택형 PR**입니다.
- Streamlit / Python / Groq / 안전한 Markdown / 기존 다크 오로라·보라/시안 디자인을 유지합니다.
- 기본 화면에는 별도 기록 목록을 추가하지 않습니다. 기존 접힌 사이드바의 **대화 기록**에서만 접근합니다.
- 데이터 파일은 프로젝트 `data/conversations.sqlite3` (기본값), Git에서 제외합니다.

## 기능

1. 사용자 입력을 모델 호출 전에 즉시 저장하고, 생성된 답변을 받은 뒤 다시 저장합니다.
2. SQLite에서 최신 대화를 자동 복원합니다. 탭 새로고침이나 Streamlit 세션 초기화 후에도 텍스트 대화가 남습니다.
3. 사이드바에서 제목과 메시지 본문을 검색하고, 목록의 대화를 클릭해 복원합니다.
4. 현재 대화 이름 변경, 확인 절차를 거치는 삭제, 새 대화 시작을 제공합니다.
5. 대화를 변경할 때는 세션에 있는 첨부 파일을 비웁니다. 첨부파일 원본·문서 원문·API 키는 DB에 저장하지 않습니다.
6. 대화의 첫 사용자 메시지를 제목으로 사용하며, 별도 이름을 지정하면 보존합니다.

## 보안 및 배포 경계 — 필독

- 기본 상태: 인증 없는 방문자는 **세션 전용 기록**만 사용합니다. 서버의 공용 SQLite를 무작정 사용하지 않습니다.
- OIDC 사용자: Streamlit 로그인 정보의 발급자·subject를 조합한 해시를 owner로 사용합니다. 모든 DB SELECT/UPDATE/DELETE는 owner별로 제한됩니다. 실제 공개 배포에서 OIDC 로그인·권한 구성과 보안 검수를 별도로 수행해야 합니다.
- 개인 PC 전용: 신뢰할 수 있는 로컬 단일 사용자 설치에서만 다음 환경 변수를 지정하세요.
  ```powershell
  $env:AI_STUDIO_SINGLE_USER_HISTORY="1"
  python -m streamlit run app.py
  ```
  이 모드는 로그인 인증이 없고 해당 앱에 접속하는 모든 사용자가 같은 대화 기록을 볼 수 있으므로 **인터넷/공유 서버에서 절대 활성화하지 마세요**.
- DB 파일은 **암호화되어 있지 않습니다**. 로컬 OS 파일 권한·디스크 암호화·별도 백업/삭제 정책이 필요합니다.
- Streamlit Community Cloud 등의 임시 파일 시스템은 SQLite 파일의 영구 보존을 보장하지 않습니다.
- `AI_STUDIO_HISTORY_DB` 환경 변수로 DB 경로를 변경할 수 있습니다. 경로는 서버 운영자가 관리합니다.
- OIDC 설정 없이 로컬 단일 사용자 모드를 활성화하지 않으면 기록 영속화는 비활성화됩니다.
