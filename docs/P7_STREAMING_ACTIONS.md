# P7 — 스트리밍·재생성·수정·복사

## 구현 범위

- 기준: P6 브랜치 `feature/p6-persistent-conversations`. P5·P6는 Draft PR 상태이므로 P7은 스택형 별도 PR이며 main을 직접 수정하지 않습니다.
- 기존 **Streamlit/Python/Groq API** 구조, Markdown 안전 렌더링, 파일 첨부, 다크 오로라·보라/시안 팔레트 및 SQLite 대화 기록을 유지합니다.
- 메시지별 추가 동작은 닫힌 상태의 **작업** 팝오버에 통합해 메인 화면을 복잡하게 만들지 않습니다.

## 기능

1. **실시간 응답**: Groq 호환 Chat Completions API를 `stream=True`로 호출하고, `st.write_stream`으로 텍스트 델타를 순차 출력합니다. 완료된 문자열만 대화 기록 및 SQLite에 저장합니다.
2. **답변 재생성**: AI 답변의 '작업 > 답변 다시 생성'으로 원래 사용자 질문 및 직전 대화 맥락을 기반으로 재요청합니다. 새 답변이 성공했을 때만 기존 답변 및 그 뒤의 대화 기록을 교체합니다.
3. **사용자 질문 수정**: '작업 > 질문 수정' 폼에서 질문을 수정한 뒤 재요청합니다. 수정 대상 이후 메시지는 무효화되며, 편집 전 안내 문구를 표시합니다.
4. **복사**: '작업'에서 `st.code(..., language=None)`의 Streamlit 기본 복사 버튼으로 원문을 복사합니다. 외부 JavaScript를 삽입하지 않습니다.
5. **오류 처리**: API 키 없음, 연결 실패, 응답 제한, 빈 응답은 거짓 성공 메시지 대신 안내만 표시합니다. 스트리밍 도중 오류가 발생한 부분 출력은 DB에 완료된 답변처럼 저장하지 않습니다.

## 첨부 및 데이터 제한

- P6는 첨부 원본 바이트를 보관하지 않으므로, 과거에 파일을 첨부한 질문의 **재생성은 지원하지 않습니다**. 파일을 다시 첨부하고 새 질문을 보내세요.
- 질문을 수정하면 첨부 상태가 초기화됩니다. 문서/이미지 컨텍스트를 조용히 재사용하지 않습니다.
- 사용자 질문은 최대 12,000자, 응답은 SQLite 한도를 고려하여 최대 100,000자까지 수용합니다.
- 재생성 성공 시 대상 답변 뒤의 대화도 제거되므로 이전 대화의 흐름을 보존하려면 새 대화를 시작해야 합니다.
- P6 영속 저장은 인증된 OIDC 계정 또는 신뢰 가능한 단일 PC 명시적 설정에서만 활성화됩니다. 기존 보안 제한은 그대로 적용됩니다.
